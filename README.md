# Task API

A simple CRUD API built with **FastAPI** as part of the FlyRank backend assignment.

This project demonstrates building a RESTful API with task management functionality, including creating, reading, updating, and deleting tasks.

## Features

- FastAPI REST API
- Health check endpoint
- CRUD operations for tasks
- Request validation with Pydantic
- Proper HTTP status codes
- Automatic Swagger/OpenAPI documentation

## Tech Stack

- Python 3.13
- FastAPI
- Pydantic
- Uvicorn
